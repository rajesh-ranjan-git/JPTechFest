## Project Overview

JP Tech Fest is a static event site for JPIET's tech fest, made up of a home page and an event details page (`event.html`), styled with Bootstrap and Sass-derived CSS.

## Features

- **Multi-Page Layout:** Home (`index.html`) and event details (`event.html`) pages.
- **Bootstrap Components:** Responsive grid and UI components from Bootstrap.
- **Sass Styling:** Sass sources alongside compiled CSS.
- **Icon Support:** Font Awesome icons used throughout the site.

## Tech Stack

- **Frontend:** HTML5, CSS3, Sass, Bootstrap
- **Icons:** Font Awesome

## Folder Structure

```bash
JPTechFest/
├── css/              # Compiled stylesheets (Bootstrap + custom)
├── sass/              # Sass source files
├── fontawesome/       # Font Awesome icon library
├── fonts/             # Custom web fonts
├── images/            # Static images used across the site
├── js/                # JavaScript used by Bootstrap/UI components
├── index.html         # Home page markup
└── event.html          # Event details page markup
```

## Installation Guide

### Prerequisites

- A modern web browser
- (Optional) A local static server such as VS Code's "Live Server" extension

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/rajesh-ranjan-git/JPTechFest.git
   cd JPTechFest
   ```

2. Open `index.html` directly in your browser, or serve the folder with a local static server:

   ```bash
   npx serve .
   ```

## Usage Instructions

1. Open `index.html` in your browser to view the fest home page.
2. Navigate to the event page to see fest event details.
